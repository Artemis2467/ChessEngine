# Chess Agent based on Reinforcement Learning

For this project, my main goal is **to code an agent that trains itself by playing chess online**. This will be done using <span style="color: purple;">**reinforcement learning**</span>. Until the present day, I have finished implementing the environment and the connection to Lichess using its API. 

There are two runnable files: <span style="color: lightblue">*main.py* and *game.py*</span>. *main.py* is used for connecting the environment, the agent and the [Lichess](https://www.lichess.org "lichess website link") website, while *game.py* is visual representation of the environment (chessboard). 

You can access the profile of the account used in the project [here](https://lichess.org/@/Art3misBot2)
